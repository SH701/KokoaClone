# 💬 KakaoTalk Clone (HTML & CSS)

> HTML과 CSS만을 사용하여 구현한 카카오톡 모바일 UI 클론 프로젝트입니다.  
> 실제 카카오톡 인터페이스를 분석하고, 화면별로 나누어 마크업 및 스타일링을 연습했습니다.

---

## 🔗 배포 링크

👉 [프로젝트 바로가기](https://your-deployment-url.netlify.app)

---

## 📸 주요 기능 및 구성

- 🧱 **HTML5 시맨틱 구조**로 화면 구성
- 🎨 **CSS 모듈 분리**로 페이지별 스타일 적용
- 📱 **카카오톡 모바일 UI 재현**
  - 친구 목록, 채팅 리스트, 더보기, 설정, 로그인 등 화면 구현
- 🎯 주요 스타일 요소: Flexbox, position, 변수(`variables.css`), reset 등

---

## ⚙️ 사용 기술

- **HTML5**
- **CSS3**
  - Flexbox, Custom Variables, Responsive Design 등
